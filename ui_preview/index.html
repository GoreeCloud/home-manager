TRANSPARENCY BY DESIGN

Know what stays private.

The preview contains only built-in fictional fixtures. These design goals are not proof that production privacy or cybersecurity integrations are implemented.

◇

No live connections

There are no backend calls, home devices, remote sessions, account tokens, or telemetry endpoints in this preview.

◈

No stored household data

The preview's fictional data is bundled in source. Appearance choices are session-only and not persisted.

✧

Consent comes first

Actual device discovery and privileged recovery require separate product permissions and tested safeguards.

Engineering boundary

GoreeShield privacy, Wardveil cybersecurity, GoreeCloud Mesh integration, and GoreeCloud Identity remain release gates. This page does not connect to or replace Home Assistant authentication.
