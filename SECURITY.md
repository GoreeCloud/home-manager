# Security policy — GoreeCloud Home Manager

This repository is a development-stage rebranded source import of Home Assistant Core.
It has **not** completed an independent security review, build, or release acceptance
process. Do not deploy it as a production service based solely on this import.

To report a suspected security vulnerability in GoreeCloud Home Manager, use GitHub
private vulnerability reporting for this repository if enabled, or contact
admin@goreecloud.com directly. Do not publish exploit details, passwords, tokens,
device addresses, personal information, or other sensitive evidence in public issues.

For an issue that also affects unchanged upstream Home Assistant Core, consult the
upstream project's current security reporting policy and coordinate responsibly.
Home Assistant and GoreeCloud are independent projects; this repository is not an
official Home Assistant distribution.

Any new automation, access to real devices, public deployment, or release must receive
a separate GoreeCloud-specific privacy, security, CI, and compatibility review.
